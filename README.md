# Лабораторная работа 6 — Функции

## Автор
Карпов Кирилл, группа ПИ-261

## Вариант
10

## Задание
Даны два массива `R` и `L` размеров `k` и `n`. Найти среднее арифметическое положительных элементов каждого массива.

В формулировке варианта в последней строке встречается обозначение массива `B`, хотя в начале варианта указан массив `L`. В программе используется `L`.

## Решение
Для обоих массивов используется одна функция `calculateAveragePositive`. Она получает вектор по константной ссылке и возвращает результат через выходной параметр. Если положительных элементов нет, функция возвращает `false`.

Ввод, вычисления и вывод разделены на отдельные блоки. Размер каждого массива должен быть от 1 до 100, модуль каждого элемента — не больше 1000.

## Формат ввода
Сначала вводятся размеры двух массивов, затем элементы первого массива `R`, затем элементы второго массива `L`.

Пример:
```text
5 4
-2 4 6 0 8
-1 3 5 -7
```

## Результат примера
```text
R: 6
L: 4
```
